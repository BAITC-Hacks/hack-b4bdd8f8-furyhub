# hack-b4bdd8f8-furyhub
Hackathon team repository for FuryHub

## Интерактивная схема для демо

```bash
python -m pip install -r requirements.txt
python run.py --data data --out out
python viz.py
python viz.py --gid 100000000343175100
python viz.py --cluster 0
```

Откройте `out/graph.html` в браузере. По умолчанию показаны топ-50 по
`priority_score` и все прямые соседи; `--gid` выбирает окружение на два шага,
`--cluster` — кластер целиком. Соседство учитывает оба направления переводов,
стрелки сохраняют направление. Флаги `--gid` и `--cluster` взаимоисключающие.
Пути можно задать через `--nodes`, `--edges` и `--output`.

Введите полный gid в поле поиска и нажмите Enter: узел выделится и окажется
в центре. Если его нет в текущем подграфе, схема переключится на его окружение
на два шага. Клик открывает карточку, двойной клик — окружение. Кнопка
«Исходный вид» возвращает начальную выборку, «Вся схема» вписывает текущую
выборку в экран. Поиск доступен по всем узлам, включая изолированные.

Цвет обозначает роль (легенда сверху), размер растёт с `priority_score`,
белая толстая рамка обозначает seed. Толщина стрелок растёт логарифмически
с суммой KZT; точная сумма доступна при наведении. Встречные переводы
отображаются отдельными изогнутыми стрелками. Подсказка узла содержит gid,
роль, priority_score и evidence.

HTML включает библиотеку и данные, работает без сервера и интернета.
На холсте находится только выбранный подграф. Координаты вычисляются при
генерации; физика в браузере отключена. В поисковом окружении центральный
узел находится в центре, прямые соседи — на первом кольце, остальные — на втором.
Gid передаются строками без потери точности длинных идентификаторов.

Проверки: `python -m unittest discover -s tests -v`; клиентская логика после
генерации HTML: `node tests/test_viz_client.cjs`.
