\# AGENTS.md



\## Контекст

Хакатон HackAlem AI, кейс Freedom «Граф денег». Пайплайн по графу переводов

назначает узлам роли, кластеры и приоритет для AML-аналитика.

ТЗ и план — в docs/PLAN.md. Стартовый код — в starter/, его не переписываем.



\## Стек

Python, pandas, networkx, pyvis. Без GPU, облака и платных сервисов.

OpenAI API — только в llm\_layer.py, ключ из .env, с фолбэком без интернета.



\## Главные файлы

\- run.py — пайплайн: python run.py --data data --out out

\- viz.py — визуализация в out/graph.html

\- out/ — три обязательных CSV: nodes\_roles.csv, clusters.csv, top\_nodes.csv



\## Правила

\- Делай только то, что просят. Не рефактори соседний код.

\- Не меняй схему CSV: обязательные колонки удалять нельзя, добавлять можно.

\- Не хардкодь gid — всё считается из данных.

\- Роли — только прозрачными правилами с порогами из словаря THRESHOLDS.

\- evidence — с числами, до 200 символов, формулировки как гипотезы для проверки,

&#x20; без утверждений о виновности.

\- Не добавляй атрибуты клиентов, которых нет в данных.

\- Полный прогон пайплайна — не дольше 5 минут.



\## Проверка перед коммитом

\- python run.py --data data --out out отрабатывает без ошибок

\- в out/nodes\_roles.csv ровно 2248 строк, пустых evidence нет

\- в out/top\_nodes.csv не меньше 20 строк



\## Git после каждой задачи

1\. Запусти проверку выше. Если упало — не коммить, сначала почини.

2\. Проверь git status: в коммит не должны попасть .env, .venv/, \_\_pycache\_\_/.

3\. Коммить только файлы, относящиеся к задаче. Сообщение — по-русски, коротко.

4\. git pull --rebase, затем git push.

5\. Если при pull --rebase конфликт — остановись, покажи конфликтующие файлы

&#x20;  и спроси, ничего не решай сам.

Запрещено: git push --force, git reset --hard, удаление веток.
